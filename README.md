# WAVE — نسخهٔ پایدارسازی‌شده

## فایل‌ها
- `server.js` — سرور Node.js، کانال‌ها، نوبت صحبت، SOS، احراز هویت مدیر و رلهٔ صوتی WebSocket.
- `index.html` — رابط فارسی موبایل و منطق سمت کاربر.
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` — فایل‌های کمکی نصب وب‌اپ.

## اجرا
به Node.js نسخهٔ 18 یا جدیدتر نیاز است. در پوشهٔ پروژه اجرا کنید:

```bash
node server.js
```

سپس برنامه روی پورت `3000` (یا مقدار `PORT`) اجرا می‌شود. برای استفادهٔ عمومی، سرور باید روی سرویس میزبانی پشتیبان Node.js مستقر شود؛ **GitHub Pages به‌تنهایی `server.js` را اجرا نمی‌کند**. می‌توانید کل پروژه را در GitHub نگه دارید و همان مخزن را به سرویس میزبانی Node.js متصل کنید.

## تنظیمات محیطی پیشنهادی
- `PORT` — پورت سرور؛ معمولاً سرویس میزبانی خودش آن را تعیین می‌کند.
- `WAVE_CODE` — رمز دعوت مشترک؛ برای محیط عمومی مقدار قوی و غیرقابل حدس انتخاب کنید.
- `WAVE_ADMIN` — رمز مدیر؛ اگر تنظیم نشود، مدیریت غیرفعال است.
- `TURN_URLS`, `TURN_USER`, `TURN_PASS` — تنظیمات اختیاری TURN برای شبکه‌هایی که ارتباط صوتی/شبکه‌ای محدود دارند؛ در این نسخه صدای اصلی از رلهٔ WebSocket عبور می‌کند و TURN برای مسیر WebRTC قدیمی/اختیاری است.

کد دعوت برای درخواست‌های HTTP از هدر فرستاده می‌شود و پس از تأیید در کوکی HttpOnly همان مرورگر نگه داشته می‌شود؛ کد دعوت در URL رویدادها قرار نمی‌گیرد. از HTTPS در استقرار واقعی استفاده کنید.

## بررسی انجام‌شده
- بررسی نحوی `server.js` با `node --check`.
- بررسی نحوی JavaScript داخل `index.html` با `node --check`.
- آزمایش اولیهٔ پاسخ `/ping`, `/ice`, `/` و `/channels` روی سرور محلی.

این‌ها آزمون‌های اولیه‌اند، نه تأیید کامل کیفیت صدا یا عملکرد هم‌زمان روی چند گوشی. قبل از استفادهٔ واقعی، دو یا چند دستگاه، قطع و وصل اینترنت، SOS هنگام اشغال موج، مجوز میکروفون، قفل صفحه و اجرای طولانی را آزمایش کنید.
